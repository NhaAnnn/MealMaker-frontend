# MealMaker

The frontend application for **MealMaker** — a simple and smart weekly meal planner.

---

## ✨ Features

- 📅 **Weekly Meal Planner:** Plan your meals for each day.
- 💡 **Smart Suggestions:** Get meal ideas based on your preferences.
- 🔍 **Recipe Search:** Find dishes by ingredients and categories.
- 🛒 **Shopping List:** Automatically generate an ingredients list.
- 📱 **Mobile Friendly:** Clean and easy-to-use interface.

---

## 🛠️ Tech Stack

- **Framework:** React Native
- **API Client:** Axios
